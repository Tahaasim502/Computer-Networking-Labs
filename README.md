# CCNA Training Labs

This repository contains networking labs I completed using Cisco Packet Tracer.

## Topics Covered

* Basic network commands
* IP addressing
* Network topologies
* DHCP
* VLANs
* Spanning Tree Protocol
* Static routing
* Dynamic routing
* RIP v2
* EIGRP
* Basic troubleshooting

## Tools Used

* Cisco Packet Tracer
* Windows Command Prompt

## Lab Files

The lab files are organized by topic. Each folder contains the related lab document and screenshots/configurations where available.

## Note

These labs were completed as part of my CCNA-level training and Computer Networks coursework.
