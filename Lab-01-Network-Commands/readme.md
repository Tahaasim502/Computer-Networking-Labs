# Lab 01 - Network Commands

This lab covers basic Windows networking commands used to check network configuration, connectivity, routes, and device information.

## Commands Practiced

- `ipconfig`
- `ipconfig /all`
- `getmac`
- `ping`
- `tracert`
- `netstat`
- `netstat -r`

## What I Learned

- How to check IP address and network adapter details
- How to view MAC address information
- How to test connectivity using ping
- How to trace the path to a destination using tracert
- How to view active connections and routing information

## Tool Used

- Windows Command Prompt
